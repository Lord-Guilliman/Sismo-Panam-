# Condiciones básicas de uso

Sismo Panamá es un proyecto independiente de consulta de reportes sísmicos públicos. Al usar la aplicación, comprendes que:

1. La información procede de fuentes externas y puede ser preliminar, tardía, corregida o estar temporalmente fuera de servicio.
2. La app no predice terremotos, no es una alerta temprana oficial y no sustituye a SINAPROC ni a otros canales oficiales.
3. La entrega de alertas locales o Web Push depende del dispositivo, el navegador, los permisos, la conectividad, los proveedores y la configuración desplegada.
4. Debes seguir siempre la orientación de las autoridades para emergencias. No demores medidas de seguridad esperando un aviso de la app.
5. Si instalas una versión de terceros, su backend, su política de privacidad y su disponibilidad pueden diferir de este proyecto original.
6. El código se distribuye bajo la licencia del repositorio. Datos, logos, marcas, mapas, sonidos y bibliotecas de terceros pueden tener condiciones distintas.

El software se proporciona según la licencia incluida y sin promesas de idoneidad para usos críticos. Para desplegarlo para el público, el operador debe ofrecer una política de privacidad coherente con el funcionamiento real y respetar las leyes aplicables. Este texto es una base informativa, no asesoría jurídica; busca revisión profesional para un servicio institucional o comercial.
